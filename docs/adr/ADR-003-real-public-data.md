# ADR-003 演示数据改为真实公开评论数据

- **日期**: 2026-11-24
- **状态**: accepted（用户明确选择「真实商品 + 真实评论，品牌匿名化」）
- **关联**: `SPEC.md` / Non-goals；`ADR-001`（部分 superseded）

## 背景

Demo 已接入真实 LLM，但种子数据全部合成。用户认为这削弱了说服力，要求换成真实数据。卖家私有的广告花费、库存、成本、转化率没有公开来源；Amazon 公开可用的真实数据是商品元数据与评论。

## 决定

- 商品标题/五点/描述/价格/评分/评论数/评论正文来自 **Amazon Reviews 2023（All Beauty）** 的固定快照。
- 5 个主 SKU 的品牌名替换为 Brand A–E；评论去除 `user_id`、图片与点赞数。
- 广告指标、库存、成本、目标 ACOS、关键词搜索量、历史 Listing 的转化率仍为模拟，在 `data/seed/PROVENANCE.md` 中逐项标注。
- `current_listing` 保留真实原文；用于生成草稿的基线会移除违规宣称，避免规则兜底直接输出违规文案。
- 数据只读边界不变：`executor` 仍只 dry-run，审批闸门仍为 `interrupt_before`。

## 备选方案

| 方案 | 结论 | 理由 |
|---|---|---|
| A 全部合成（现状） | 被替代 | 与真实 LLM 不匹配，说服力弱 |
| B 真实公开数据 + 模拟广告 | **采用** | 可公开复现、无账号、无版权图片，边界清晰 |
| C 接真实 SP-API / Ads API | 拒绝 | 需要卖家账号与密钥，演示不可复现 |

## 理由

- 公开数据可固定快照与 sha256，评测仍可重复。
- 品牌匿名化避免把真实品牌的负面评论做成公开演示素材。
- 广告数据没有公开来源，明确标注模拟比伪造真实感更可信。

## 影响

- 数据：`data/fetch_real_seed.py` 成为当前种子入口；`data/generate_seed.py` 仅保留合成兜底并加防覆盖保护。
- 评测：`evals/golden.jsonl` 的关键词随商品变化重写；这是数据源变更，不是放宽验收。
- 许可：Amazon Reviews 2023 面向研究/非商业用途，Demo 需保留引用与免责声明。
- 回滚：删除 `data/seed/.real_data` 后可重新运行 `data/generate_seed.py` 回到合成数据。
